# research-visuals

Interactive figures for my research.

## `eff_toff/`: d-level OR tree construction

A React viewer for a d-level tree of OR gates over k parities of the input, built with reused workspace
qubits, from my work on T-efficient Toffoli gates. One tab shows the tree for d = 3, m = 2 (k = 8 parities),
the other the corresponding circuit.

```
cd eff_toff
npm install
npm run dev        # then open http://localhost:5173
```
